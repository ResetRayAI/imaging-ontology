# Imaging Semantic Graph

The public imaging semantic graph describes relationships between:

- CT attenuation;
- ROI;
- quantitative imaging;
- anonymized metadata;
- structured exports;
- AI-readable terminology.

# Semantic Goal

The graph is intended for:

- semantic interoperability;
- machine-readable imaging semantics;
- structured imaging workflows;
- AI-readable quantitative imaging documentation.
