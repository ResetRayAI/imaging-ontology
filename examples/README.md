# RSIF Examples

Synthetic RSIF examples for AI-readable quantitative CT/DICOM workflows.

This repository contains safe, synthetic examples of ResetRay Structured Imaging Format.

## Scope

Examples include:

- vertebral attenuation;
- liver attenuation;
- liver-spleen comparison;
- technical quantitative CT parameters.

## Important

All examples are synthetic.

This repository does NOT contain:

- real patient data;
- real DICOM files;
- medical conclusions;
- diagnoses;
- treatment recommendations.
