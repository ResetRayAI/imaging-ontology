# CT Attenuation Relationships

## Semantic Relationships

CT attenuation:

- measured_in → Hounsfield Units
- measured_using → ROI
- affected_by → reconstruction kernel
- affected_by → slice thickness
- affected_by → scanner variability
- represented_in → structured export
- mapped_to → RSIF objects

---

# Scope

These relationships describe technical imaging semantics only.

They are not intended for:

- diagnosis;
- disease interpretation;
- treatment recommendation;
- clinical decision support.
