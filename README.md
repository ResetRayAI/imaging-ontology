# Imaging Ontology

## Repository Role

Frozen ontology-oriented satellite layer for classes, relations and mappings.

**Status:** Frozen satellite.

This repository records the public ontology-shaped layer around structured quantitative imaging concepts. It should stay narrow, readable, and stable.

## What This Repository Contains

- Ontology-oriented classes
- Semantic relations between imaging concepts
- Mapping notes between ontology entities and structured representations
- Synthetic ontology examples

## What This Repository Does Not Contain

- Production ResetRay systems
- Internal orchestration logic
- ROI placement methodology
- Scoring systems
- Clinical workflows
- Diagnostic algorithms
